# 人工智能专业 · 职业生涯规划学习实践工作台

> **在线网址（作业提交用）**：<https://ricepaper921.github.io/ai-career-workbench/>
> 仓库地址：<https://github.com/ricepaper921/ai-career-workbench>

面向人工智能专业学生的**离线单文件网站**：一个 `index.html`，零依赖、零安装、零联网，手机 / 平板 / 电脑都能直接打开。

> 修改内容后，在站点目录执行 `git add -A && git commit -m "更新" && git push`，约 1 分钟后线上网址会自动同步。

---

## 一、怎么打开

| 场景 | 做法 |
| --- | --- |
| 电脑 | 双击 `index.html`，用任意现代浏览器打开（Chrome / Edge / Firefox / Safari 均可） |
| 手机 / 平板（同一 Wi-Fi） | 双击本目录下的 **`分享到手机.bat`**，窗口里会列出 `http://192.168.x.x:8000` 这样的地址，手机浏览器直接打开即可 |
| 手机 / 平板（不同网络） | 把 `index.html` 通过微信、AirDrop、QQ、网盘发过去，用浏览器打开；或用下面的「放在网上」 |
| 放到网上（推荐，最稳） | 把 `index.html` 拖到 Netlify Drop / Cloudflare Pages / GitHub Pages / Vercel，得到一个网址，任何设备打开同一个链接即可 |

> **`分享到手机.bat` 使用说明**：需要电脑上有 Python（本机已具备）。双击后保持窗口开着即为"正在分享"，手机需要和电脑连**同一个 Wi-Fi**；关掉窗口即停止。
> 若手机打不开，通常是三种原因：不在同一 Wi-Fi、Windows 防火墙拦了入站（选"专用网络"允许即可）、或者校园网/公共网络开启了**设备隔离**（这种网络下请改用"放到网上"的方式）。

> 整个站点只有 1 个 HTML 文件，不引用任何 CDN、字体、图片或外部脚本，**断网也能正常使用**。

## 二、它解决什么问题

AI 专业的学生最常见的困境是：课程学了、方向很多、但不知道**自己现在在哪、下一步该做什么、离目标岗位还差多少**。
这个工作台把这件事拆成七个互相联动的模块，并用一套进度引擎把它们串起来。

| 模块 | 内容 |
| --- | --- |
| 📌 总览 | 整体进度环、四项进度看板、**自动生成的下一步建议**、学习打卡与八周热力图 |
| 🧭 岗位地图 | 12 个 AI 相关岗位：核心职责、必备技能、加分项、入门门槛、典型公司、参考月薪、**能力基准** |
| 📈 能力自评 | 八维能力打分，生成**雷达图**（实线＝我的水平，虚线＝目标岗位基准），输出差距清单 |
| 🗺️ 学习路线 | 大一 → 大二 → 大三 → 大四 → 读研五阶段任务清单（含资源），逐项勾选 |
| 🧪 实践项目 | 12 个由浅入深的项目（入门/进阶/高阶），含任务拆解、数据工具、交付物标准 |
| 🎤 求职准备 | 面试知识清单（7 大类）、招聘时间线、简历与投递要点 |
| 🗂️ 我的档案 | 学业信息、经历记录（科研/竞赛/实习/项目）、数据导出与导入 |

**联动逻辑**：在「能力自评」里给某项打分，总览的「下一步建议」会立刻重算——它会指出你最该补的短板、该从哪个项目起步、当前阶段还差几项任务，并给出直达按钮。

## 三、关于数据

- 所有勾选、打分、经历记录、打卡**只保存在本机浏览器**（localStorage），不联网、不上传。
- 换设备、换浏览器、清理浏览器数据都会导致进度丢失，请用「导出备份」保存 JSON 文件。
- 「导入备份」支持选择文件或直接粘贴 JSON 内容，在另一台设备上即可完全恢复。
- 隐私模式 / 部分手机浏览器可能禁用本地存储，此时页面仍可正常使用，只是不会保存（顶部会给出提示）。

## 四、想自己改内容

所有内容都是文件末尾 `<script>` 里的纯数据结构，改起来不需要任何构建工具：

| 想改什么 | 改哪 |
| --- | --- |
| 岗位 | `CAREERS`（`dims` 是雷达图对照基准，取值 0–5） |
| 能力维度 | `DIMS` |
| 学习路线 | `ROADMAP`（其中 `res` 每一项是 `{ n: 名称, u: 网址 }`，省略 `u` 就显示为不带链接的标签） |
| 实践项目 | `PROJECTS`（其中 `data` 是数据集/工具列表，同样是 `{ n, u }`，省略 `u` 即无链接） |
| 面试清单 | `PREP` |
| 招聘时间线 / 简历要点 | `JOBTIMELINE` / `RESUME_TIPS` |

改完保存、刷新浏览器即可生效。修改前建议先备份一份原始文件。

## 五、兼容性说明

- 目标浏览器：Chrome / Edge 90+、Firefox 90+、Safari 15+、各安卓与 iOS 现代浏览器。
- 响应式断点：900px（手机竖屏单列 → 桌面侧边导航）、1280px（宽屏留白优化）。
- 支持深浅色主题（可手动切换或跟随系统）、键盘操作、`Ctrl/Cmd + P` 打印为 PDF。
